# Rushikesh More Patil - Premium Developer Portfolio

A modern, premium portfolio website showcasing backend/full-stack development expertise in MERN stack technologies. Built with React, Tailwind CSS, and Framer Motion for a professional, startup-grade experience.

## 🚀 Live Demo

[View Portfolio](https://your-portfolio.vercel.app) (Deploy on Vercel)

## ✨ Features

- **Premium Design**: Glassmorphism cards with backdrop blur effects
- **Dark/Light Mode**: Seamless theme switching with local storage persistence
- **Responsive Layout**: Mobile-first design that works on all devices
- **Smooth Animations**: Framer Motion powered transitions and hover effects
- **Fast Performance**: Optimized with Vite for lightning-fast loading
- **Professional Sections**:
  - Hero with compelling introduction
  - About section with professional summary
  - Skills grouped by expertise areas
  - Featured projects with detailed descriptions
  - Experience showcase
  - Contact form with social links

## 🛠️ Tech Stack

- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS 3.4
- **Animations**: Framer Motion
- **Deployment**: Vercel
- **Fonts**: Inter (Google Fonts)

## 📋 Prerequisites

- Node.js (v16 or higher)
- npm or yarn

## 🏃‍♂️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 🚀 Deployment

### Vercel (Recommended)

1. **Build for production**
   ```bash
   npm run build
   ```

2. **Deploy to Vercel**
   - Connect your GitHub repository to Vercel
   - Or upload the `dist` folder manually
   - Set build command: `npm run build`
   - Set output directory: `dist`

### Other Platforms

The `dist` folder contains the production build and can be deployed to:
- Netlify
- GitHub Pages
- AWS S3 + CloudFront
- Any static hosting service

## 🎨 Customization

### Content Updates

Edit the following in `src/App.jsx`:
- Personal information and bio
- Skills and technologies
- Project descriptions and links
- Experience details
- Social media links

### Styling

- Colors and themes: `tailwind.config.js`
- Global styles: `src/index.css`
- Component styles: Inline Tailwind classes

### Assets

- Add your resume to `public/resume.pdf`
- Update favicon in `public/`
- Add project images to `public/` if needed
